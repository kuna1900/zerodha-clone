# Zerodha Clone 🚀

A full-stack stock trading platform inspired by **Zerodha Kite**, built using the **MERN Stack**. This project provides users with an interactive dashboard to manage holdings, positions, watchlists, and stock-related activities in a modern UI.

---

## 🌟 Features

- 📈 Interactive stock dashboard
- 📊 Portfolio management system
- ⭐ Watchlist for tracking stocks
- 🛒 Orders & Positions management
- 🔐 User Authentication
- ⚡ REST API integration
- 📱 Responsive UI design
- 💾 MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kuna1900/zerodha-clone.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd zerodha-clone
```

### 3️⃣ Install Dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd backend
npm install
```

---

## ▶️ Run the Project

### Start Backend Server

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file inside the backend folder and add:

```env
MONGO_URL=your_mongodb_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```
